# Ночная карта Екатеринбурга

Статическое веб-приложение, импортированное из предоставленного `index.html`.
Разметка, стили и встроенный набор заведений в этом файле оставлены без изменений.

## Состав

- `index.html` — исходная страница, стили, интерактивность и массив данных `venues`.
- `server.js` — минимальный сервер для `/` и `/index.html`; `/health` используется для проверки готовности.
- `Dockerfile` — запуск приложения на Node.js 22.

Сервер не записывает и не меняет данные: поиск, фильтры, карта и карточки работают с
набором, встроенным в `index.html`. База данных и серверная синхронизация не подключены.

## Внешние ресурсы

Для отображения карты страница загружает Leaflet с `unpkg.com` и тайлы OpenStreetMap.
Поэтому для карты нужен доступ браузера к этим внешним сервисам.

## Запуск

В среде Node.js 22 запустите `node server.js`. Сервер слушает `0.0.0.0` на порту
из переменной `PORT` (по умолчанию `10000`). В разработке разрешены локальные адреса
и имя хоста из `AMAZI_PREVIEW_HOST`.
